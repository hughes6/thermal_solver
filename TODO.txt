e3Symbol.Place( shti, x, y, rot, scale, maintaintextsize ) 

Syntax

Integer Place( [in]Integer shti, [in]Double x, [in]Double y, [in][optional]String rot, [in][optional]Double scale, [in][optional]Integer maintaintextsize )

Description

Creates and places a symbol item or moves the current symbol item's position within the project.

Parameters





Type Parameter Description 
[in]Integer shti Identifier of the sheet 
[in]Double x Placement position on the x-axis 
[in]Double y Placement position on the y-axis 
[in][optional]String rot Rotation and mirroring value 
See Rotation for possible values.

Default is no rotation or mirroring
 
[in][optional]Double scale Scale factor value 
Default is no scaling
 
[in][optional]Integer maintaintextsize Indicates whether symbol text items should also be scaled to the scale value 
If 1, the text items are not scaled

If 0, the text items are scaled

Default value is 0
 

Return Values





Value Status Description 
> 0 Success Identifier of the placed symbol item 
0 Failure Error occurred 

Remarks

If the symbol item is assigned using Load(), a new symbol is created and becomes the symbol object's current symbol item.

If the symbol item is an unplaced gate, a new symbol is created and becomes the symbol object's current symbol item.

If the symbol item is a placed symbol, the symbol is moved. If connection lines are already connected to the symbol, the symbol cannot be moved to another sheet or rotated.

x and y values should be in project measurement units.

scale should be expressed as a decimal value. For example, a value of 2.0 will scale the symbol to twice the size.

Examples

The best results from the example can be achieved by opening an E³.series project and opening a sheet.


Visual Basic Script


Set e3Application = CreateObject( "CT.Application" ) 
 
Set e3Job = e3Application.CreateJobObject()
 
Set e3Sheet = e3Job.CreateSheetObject()
 
Set e3Symbol = e3Job.CreateSymbolObject()
 
 
 
Dim symbolName : symbolName = "ZUK06-15-03"
 
Dim symbolVersion : symbolVersion = "1"
 
 
 
Dim rotation : rotation = "0"
 
Dim scale : scale = 1.0
 
Dim keepTextScale : keepTextScale = 1
 
 
 
sheetId = e3Job.GetActiveSheetId()        'get currently open sheet id
 
If sheetId > 0 Then
 
    
 
    'get the drawing area of the sheet
 
    e3Sheet.SetId sheetId
 
    embeddedSheetCount = e3Sheet.GetEmbeddedSheetIds( embeddedSheetIds )
 
    If embeddedSheetCount > 0 Then
 
        sheetId = e3Sheet.SetId( embeddedSheetIds( 1 ) )
 
    End If    
 
    sheetName = e3Sheet.GetName()
 
    e3Sheet.GetDrawingArea sheetMinimumXPosition, sheetMinimumYPosition, sheetMaximumXPosition, sheetMaximumYPosition    
 
        
 
    isLoaded = e3Symbol.Load( symbolName, symbolVersion )        'load symbol from database
 
    If isLoaded > 0 Then    
 
    
 
        e3Symbol.GetArea symbolMinimumXPosition, symbolMinimumYPosition, symbolMaximumXPosition, symbolMaximumYPosition
 
    
 
        'Find position in the middle of the sheet
 
        sheetCenterXPosition = ( sheetMaximumXPosition - sheetMinimumXPosition ) / 2
 
        sheetCenterYPosition = ( sheetMaximumYPosition - sheetMinimumYPosition ) / 2
 
        symbolCenterXPosition = ( symbolMaximumXPosition - symbolMinimumXPosition ) / 2
 
        symbolCenterYPosition = ( symbolMaximumYPosition - symbolMinimumYPosition ) / 2
 
    
 
        placementXPosition = sheetCenterXPosition - symbolCenterXPosition
 
        placementYPosition = sheetCenterYPosition - symbolCenterYPosition
 
            
 
        result = e3Symbol.Place( sheetId, placementXPosition, placementYPosition, rotation, scale, keepTextScale )
 
        If result = 0 Then
 
            e3Application.PutError 0, "Error placing " & symbolName & " version " & symbolVersion & " on sheet " & sheetName
 
        Else
 
            e3Application.PutInfo 0,"Symbol " & symbolName & " version " & symbolVersion & " placed on sheet " & sheetName                
 
        End If
 
            
 
    End If
 
Else
 
    e3Application.PutInfo 0, "No open sheet"
 
End If
 
 
 
Set e3Symbol = Nothing
 
Set e3Sheet = Nothing
 
Set e3Job = Nothing
 
Set e3Application = Nothing

e3Job.SetBlockReferenceType( newtype ) 

Syntax

Integer SetBlockReferenceType( [in]Integer newtype )

Description

Sets the value of the block reference type setting.

Parameters





Type Parameter Description 
[in]Integer newtype Setting value to apply 

Return Values





Value Status Description 
1..3 Success Previous block reference type setting value 
0 Failure Error occurred 

Remarks

The setting value can also be modified using SetSettingValue() with a setting value name of BLOCKREFSORT

The setting location within E³.series is Settings → Placement → Block → Type.

valid values for newtype and the return value can be one of the following values:




Value Description 
1 All 
Every block symbol contains references to all other split block symbols
 
2 Origin 
One block symbol is defined as the source and all other blocks as destinations

The source references all destinations and all destinations reference the source
 
3 Position 
Refers to the previous block symbol and to the next block symbol for each block symbol

The reference calculation takes place according to the page number and block position
 

The value of the block reference type setting can be retrieved using GetBlockReferenceType().

Examples

The best results from the example can be achieved by opening an E³.series project.


Visual Basic Script


Set e3Application = CreateObject( "CT.Application" ) 
 
Set e3Job = e3Application.CreateJobObject()
 
 
 
Dim blockReferenceType : blockReferenceType = 1        'all
 
 
 
result = e3Job.SetBlockReferenceType( blockReferenceType )
 
Select Case result
 
Case -1
 
    e3Application.PutError 0, "Error setting block reference type value"
 
Case 1
 
    e3Application.PutInfo 0, "Block reference type setting value changed from all to all"
 
Case 2
 
    e3Application.PutInfo 0, "Block reference type setting value changed from origin to all"
 
Case 3
 
    e3Application.PutInfo 0, "Block reference type setting value changed from position to all"
 
End Select 
 
 
 
Set e3Job = Nothing 
 
Set e3Application = Nothing
